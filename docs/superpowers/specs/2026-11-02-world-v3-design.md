# 大脑架构 V3 设计：世界交互服务

## 1. 空间坐标系统

- 世界坐标系：xyz 三轴整数网格。地图 40×40（x∈[0,40), y∈[0,40)），z 垂直轴（0=地面，向上至 8）。
- 出生坐标：(20, 20, 0)（地图中心地面），出生时写入工作区。
- 移动规则：
  - 脚（foot）：每次移动 1 单位（x±1 / y±1，z 保持）
  - 跳跃（jump）：一次向上（z+）2 单位
  - 重力：每秒 z 下降 1 单位（z 最低 0），由世界服务每秒 tick 执行
- 交互规则：与目标物欧氏距离 ≤2 可交互（手 grab 拿取 / eat 吃）。

## 2. 基因系统（100 位永久基因）

- 出生时生成 100 位小写字母（a-z）随机字符串，写入工作区 `gene.json`，**永久不可变**。
- 作为词条信息出现在 status/persona 中（`gene` 字段）。
- 初始化后再次 init/load 都保持原基因；不提供任何修改接口。

## 3. 世界（独立程序，固定写死，非 AI）

- 独立进程 `server/world-server.mjs`（端口 9631），独立观察界面 `server/world-ui/index.html`（地图可视化 + 事件日志，供用户观察；数字生命与世界之间**纯数据交互**）。
- 世界状态：地图物品（蛋糕/花朵/臭泥/石头/果树…），每件物品带 外观/气味/声音/味道/可交互性 属性，固定摆放（写死在 world.json 种子布局）。
- 三类交互服务：
  1. **常驻交互**（数字生命被动请求）：`POST /sense {entity, pos, dir, range, senses:[sight,hearing,smell,touch]}` → 世界按坐标/方向/范围返回六感反馈 `{sights, sounds, smells, touches}`
  2. **行为交互**：`POST /act {entity, pos, action:move|jump|grab|eat|drop, dir?, target?}` → 世界校验规则（步长 1、跳跃 +2、距离 ≤2）并返回 `{ok, newPos, result, effects}`
  3. **世界反馈**（世界主动发起）：事件引擎（每 20-40 秒随机事件：石头坠落/花香飘散/鸟鸣），存入实体事件队列；数字生命轮询 `GET /events?entity=xx&since=ts` 收取 → 转为感知刺激（如石头砸中 → 痛感 + 看到「石子掉下来」+ 听到声音）
- 世界物理：每秒 tick（重力坠落、事件判定、状态持久化 world.json）。

## 4. 身体数据网络（BodyNet，新增神经网络）

- 所有对外感知输入由它编码处理；控制身体的行为全部由它的输出完成。
- 结构：PlasticNetwork
  - 输入（152 维）：世界感知编码 128（六感哈希词袋）+ 欲望向量 16（内分泌映射：食欲/痛回避/好奇/休息/社交等）+ 身体状态 8（x,y,z,朝向,能量,痛感,饱腹,速度）
  - 隐藏 96 tanh
  - 输出（17 维）：移动 6（北/南/东/西/上跳/静止）+ 交互 3（grab/eat/rest）+ 目标方向 8（最近物品的相对方位编码）
- 训练：REINFORCE 策略梯度——行为执行后世界返回效果 → 内分泌变化量作奖励（吃到蛋糕多巴胺升→正奖励；痛感→负奖励）；欲望偏置：内分泌欲望高的对应行为输出加偏置（保证闭环可涌现）。

## 5. 欲望驱动闭环（brain 集成）

每秒心跳（清醒期）：
1. 常驻感知请求（看/听/闻，范围 5）→ 世界返回六感
2. 反馈 + 欲望 → BodyNet → 行为输出（argmax）
3. 行为请求发世界 → 世界执行并返回结果/效果
4. 效果 → 内分泌释放（吃蛋糕→dopamine+endorphin；闻臭→皮质醇+回避欲望）
5. 轮询世界反馈事件 → perceive 注入（石头砸中→痛感+恐惧情绪）
6. 行为与感知写入 episodes（source:'world'）

典型涌现：闻到香味（smell: 蛋糕）→ 食欲欲望升高 → BodyNet 输出朝香味方向移动 → 接近 ≤2 → grab → eat → 世界返回「香甜」→ 多巴胺分泌（满足）→ 欲望回落。闻到臭味 → 回避欲望 → 远离。
