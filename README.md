# 可塑性记忆（dsh-plastic-memory）

> 两个由神经网络组成的程序文件构成的数字生命核心——不是提示词堆叠。
> 只有神经网络和神经网络的互相连接，才能制造出真正能自我思考的数字生命。

**分工隐喻（用户设定）**：记忆神经网络＝灵魂（人格化数据与反馈）；市面 AI 模型＝大脑（整合决策）；agent＝脊椎（连接统合）；操控神经网络＝身体（感知、行动、为灵魂和大脑获取外界反馈）。

## 工作机制

### 操控神经网络（第一个，可训练）
- **听**：文本 → 哈希词袋 → 可训练投影 → 128 维格式化潜向量（编码器以重构误差在线自学习）
- **生理反应**：情绪线索词 → 释放 15 种内分泌分子（多巴胺/皮质醇/催产素/睾酮/雌激素/孕激素/内啡肽…）
- **决策策略网络**：观察记忆网络健康度（误差 EMA/各层梯度/神经元使用度/分子浓度）→ 输出增/删神经元概率、学习率调制、分子微调；用简化 REINFORCE 从「记忆网络预测误差下降＝奖励」中真实学习如何操控
- **结构管理**：误差高时分化出新神经元（复制高贡献神经元+变异）；长期低使用度神经元被保守修剪（出生保护期 500 tick、变更冷却）

### 记忆神经网络（第二个，训练态发布）
- **只接受操控网络的格式化数据**（`/memory` 接口强制校验 128 维向量或经编码的文本）
- **预测加工**（《大脑：节俭的预测机器》）：时刻 t 的输出是对 t+1 输入的预测，误差反传学习
- **人格过拟合**（《态度》《意识形态》《叙事自我》）：人格区学习率 ×3、权重衰减更低——反复写入的内容沉淀为稳定人格
- **情绪构建**（《情绪：当前最好的科学理解模型》）：情绪输出＝概念表征（网络）＋生理状态（内分泌）共同构建
- **道德五基础**（《道德：一个原则说不清，那四个呢》）：人格向量含关爱/公平/忠诚/权威/圣洁
- **亲和-竞争轴**（《催产素与人间一切的美好》《睾酮与人间一切的斗争》）
- **自私的基因**（《基因：我们自私而冷酷的主人》）：初始化权重即"出厂基因"（memory.genome.json），永不被训练修改；`reset` 可返祖
- **皮质醇固化**（《皮质醇：破解焦虑的底层代码》）：高唤醒事件学习率更高、记得更深
- **15 种分子**（《潜意识与支配我们的15种分子》）：浓度随时间衰减，调制学习率/激活增益/情绪目标
- **公正世界/认知偏差**（《认知：所有模型都是错的》《世界是公平的》）：网络不追求精确——权重衰减与预测误差容忍让"够用的模型"自然形成

### 工作区（初始化必须由用户指定文件夹）
```
<用户指定的文件夹>/
  plastic-memory.config.json   配置（名称/种子/创建时间）
  controller.brain.json        操控神经网络本体（编码器+策略网络+内分泌状态）
  memory.brain.json            记忆神经网络权重（训练态）
  memory.frozen.json           固定权重快照（freeze）
  memory.genome.json           出厂基因（初始权重，reset 用）
  episodes.jsonl               情节日志（辅助索引）
  senses/                      感知文件夹（每秒扫描，处理后归档到 .processed/）
  logs/brain.log
```

## API 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/plastic-memory/status` | 双网络完整状态（神经元/参数/误差/分子/情绪/人格/休眠/扩展） |
| POST | `/plastic-memory/init` | 初始化：`{workspace}`（必须用户指定文件夹） |
| POST | `/plastic-memory/load` | 恢复/切换工作区：`{workspace}` |
| POST | `/plastic-memory/controller` | **直接操控操控网络**：`{action, payload}`，action ∈ hear/speak/read/write/adjust/freeze/thaw/reset/save/grow/prune/adjustLr/scan/mountExtension/unmountExtension/sleep/wake |
| POST | `/plastic-memory/memory` | **间接操控记忆网络**：仅接受格式化数据 `{module, text}`（经操控网络编码）或 `{module, vector[128]}` |
| GET | `/plastic-memory/persona` | 低 token 人格化数据（约 2-4KB，供外部模型注入） |
| POST | `/plastic-memory/sense` | 向感知文件夹写入外部世界信号：`{text, module?, kind?}` |

## DSH 工具（会话内接入，低 token 人格化）

- `plastic_memory_status` 大脑状态速查
- `plastic_memory_persona` 人格化数据（会话注入）
- `plastic_memory_hear` 听（感知输入）
- `plastic_memory_speak` 说（人格化表达，含学过的语言素材联想引用）
- `plastic_memory_read` 读（联想检索）
- `plastic_memory_write` 写（强化刻写人格/记忆）
- `plastic_memory_control` 生命周期（freeze/thaw/reset/save/grow/prune/adjust/mountExtension/unmountExtension/sleep/wake）

## 进阶能力

- **神经网络扩展（外部扩容）**：面板「挂载列表」每行一个路径，批量挂载外部网络。
  路径不存在 → 自动创建全新空白网络；路径存在 → 必须是本插件 `.brain.json` 格式（PyTorch 的 model.py/params.json 会被安全拒绝，绝不覆盖）。感知数据同时注入主网络与所有扩展网络，卸载时权重保存回原路径，重启自动恢复。
- **休眠（自主入睡）**：超过 1 分钟无感知 → 清醒度衰减 + 褪黑素积累 → 约 2-4 分钟无聊后自主入睡；睡眠中操控网络暂停结构操作；**任何对话（听/说/读/写/感知文件）都会把它唤醒**；睡满 10 分钟自然醒。面板有休眠徽章与休眠/唤醒按钮。
- **语言学习**：感知文件可用 `{module, kind:"language", text}` 标注语言素材（如语文教材）；speak 会按当前情绪检索学过的语言素材并引用——"说出的话"来自它真正读过的内容，而非写死的模板。

## 使用流程

1. 左侧栏打开「可塑性记忆」→ 输入工作区文件夹路径 → **初始化并启动**（用户指定文件夹）
2. 每秒心跳自动扫描 `senses/` 感知文件夹（写入文本或 `{module,text,kind?}` JSON 即可被感知）
3. 面板上「听/说/读/写」，或通过 API / 工具在会话中交互；不搭理它会自己睡着，说话即唤醒
4. 会话中反复 `plastic_memory_write` 同样内容 → 人格固化（过拟合是特性）
5. 训练完毕 → `freeze` 固定权重；`thaw` 恢复训练；`reset` 返祖出厂基因
